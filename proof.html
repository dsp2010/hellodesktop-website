A CONTROLLED TEST, NOT A CLAIM

A booking you can follow.

Run these checks with the team against the agreed supported integration. This website does not run or certify them.

  1. 01

    Set up a controlled test

    Use an agreed test calendar, fictional customer details and the shop’s approved services, durations and staff availability.

  2. 02

    Make the call

    Ask for a service, preferred barber and time. Check that the receptionist follows corrections and repeats the intended details.

  3. 03

    Show the accepted appointment

    Inspect the actual connected calendar. The staff member, service, duration, time and booking reference must match the request. Only then is a booking confirmed.

  4. 04

    Change it, then test a failure

    Check that a reschedule or cancellation affects the right appointment. Try an unavailable slot, a retry and a rejected calendar request; a failure must not become a confirmation.

EVIDENCE FROM THE ACTUAL PILOT

Measure what happened.

During a pilot, record accepted appointments, correct changes and cancellations, handovers, failures, and the minutes and messages used. Review the underlying records before publishing a result.

There are no customer results or testimonials on this page unless genuine, reviewed feedback has been supplied with permission.

Before real callers rely on it

  • Supported booking access is confirmed.
  • Shop rules and caller privacy information are agreed.
  • Calendar and telephone tests are reviewed.
  • The owner approves the handover and go-live.
