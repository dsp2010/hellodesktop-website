RECEPTIONIST EXAMPLE · ABOUT 45 SECONDS

One call.
A clear next step.

See how an appointment request could be handled, including what happens when it cannot be completed.

Example only — no real appointment is made. This is a written illustration, not a working telephone service. Real bookings need a supported connection that has been tested.

FICTIONAL SHOP / CEDAR & COMB4 short steps

01 / THE REQUEST

A customer needs a haircut.

Customer

“Could I book a haircut tomorrow afternoon?”

Assistant

“Of course. Would you like a particular barber?”

02 / THE DETAILS

Understand what they need.

Customer

“A standard haircut with Sam, please. My name is Alex.”

Assistant

“I’ll check a 30-minute haircut with Sam. What’s the best contact number?”

All names and details are fictional. This example asks you for no personal information.

03 / THE CHECK

Check before promising.

↔
Illustrative booking-system check

Check Sam’s diary, the service length and the requested time. Recheck the slot when saving the booking.

Assistant

“There’s a 3pm slot. Shall I try to book that for you?”

An available time is not yet a confirmed booking.

04 / THE RESULT

Confirm only after acceptance.

IF ACCEPTED

The booking is saved.

“The booking system has confirmed your haircut with Sam tomorrow at 3pm.”

IF IT CANNOT BE COMPLETED

Offer another next step.

“I couldn’t confirm that time. We can try another slot or ask the shop to follow up.”

A lost connection or unanswered request must not be described as a confirmed appointment.
